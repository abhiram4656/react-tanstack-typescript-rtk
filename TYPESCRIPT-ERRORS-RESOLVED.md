## Summary of Issues

### Issue 1: Query Function Type Mismatch
**Root Cause:** TanStack Query expects `queryFn` to have signature `(context: QueryFunctionContext) => Promise<TData>`, but we were passing a service method with different parameters directly.

**Solution:** Wrap service calls in arrow functions to match expected signature and ignore the context parameter when not needed.

### Issue 2: Custom Axios Config Type Not Recognized
**Root Cause:** TypeScript's structural typing system doesn't automatically recognize our `CustomAxiosRequestConfig` extension when spreading config objects. The base `AxiosRequestConfig` doesn't have a `meta` property.

**Solution:** Use type assertions (`as CustomAxiosRequestConfig`) to explicitly tell TypeScript that our config objects include the extended interface with the `meta` property.
